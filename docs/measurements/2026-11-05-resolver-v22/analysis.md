# 해석기 v2.2 재해석 — 분석 노트

## 목적

R2 스크리닝 1·2회차([r2-screen](../2026-11-04-r2-screen/analysis.md))에서 해석에 실패한 82곡만 다시 해석해, 해석기 v2.2의 효과와 오매칭을 확인한다. 선곡은 다시 하지 않았다.

- v2.2: 검색이 원곡을 돌려주지 않을 때만 그 아티스트의 곡 목록(lookup)에서 찾는다. 이미 찾던 곡은 경로가 그대로다.
- 고친 원인(11/5 실측): 검색 API는 explicit 곡을 아예 돌려주지 않는다. 한국 곡은 US·KR trackId가 달라 KR 표기 조회가 0건일 수 있다.
- 코드: 선곡 `cec89c7`(두 회차 picks 280응답을 합침), 재해석 `5f45c22`

## 결과

82곡 중 **54곡**을 새로 찾았다. 이 54곡은 두 회차 선곡에 316번 등장하는 자주 쓰이는 곡이었다(자이언티 '양화대교', 악동뮤지션, DAY6 등).

- 새로 찾은 54곡 중 9곡이 explicit이었다(Green Day 'American Idiot', Alanis Morissette 'You Oughta Know', Bon Iver 'Holocene', Lana Del Rey 등). 검색이 explicit 곡을 빼는 문제가 실제 실패 원인이었음을 확인했다.

## 새로 찾은 곡 수동 확인

54곡 모두 앨범명·발매연도까지 조회했다. 47곡은 원 앨범·싱글·OST 수록 원곡이다. 표기가 낯설지만 맞는 경우도 있다.

- 松任谷由実 → 荒井由実: 같은 사람의 결혼 전 활동명이며 1975년 원곡이다.
- 이진아 '밤과 별의 노래' → ONEW & Lee Jin Ah: 실제 듀엣곡이다.
- DAY6 '파도가 끝나는 곳까지' → DAY6 (Even of Day): 유닛 곡이다.

## 함께 고친 것 (`5f45c22` 다음 커밋)

1. **곡 목록 단계는 곡명이 정확히 같은 곡부터 본다.** 위 'Piano Nocturn' 오매칭을 고친다. 원곡이 없으면 순서는 그대로다.
2. **지역 쿼터는 1아티스트 1곡을 artistId로 판정한다.** 곡 목록 단계는 KR 스토어 표기(데이식스, 악뮤)를 돌려준다. 이름으로 비교하면 검색 단계의 'DAY6'와 한 목록에 함께 들어갈 수 있다. artistId는 스토어가 달라도 같다.
   - 기존 중복 제거 테스트는 중복 후보의 점수가 쿼터 밖이라, 중복 제거를 빼도 통과했다. 함께 고쳤다.

## 남은 결정

- **라이브 앨범 수록본**: 해석된 1,042곡 중 7곡(0.7%)이 곡명에는 표기가 없는 라이브 앨범 수록본이었다(검색 단계 5, 곡 목록 단계 2). 앨범명으로도 대체 버전을 판정할지 정해야 한다.
- 화면의 아티스트 표기가 섞인다(검색 단계 'DAY6', 곡 목록 단계 '데이식스'). 영향이 작아 기록만 한다.
