# 분석 노트 — 2026-11-11 R5 최종 비교 (기준선 11/2 vs 지금 운영)

## 목적과 조건

재설계 전과 지금 운영을 같은 입력 · 같은 간격으로 비교한다. 방식과 판정 기준은 측정 전에 [eval README "R5 최종 비교"](../eval/README.md)에 고정했다(11/11).

- 기준선 [`2026-11-02-baseline`](../2026-11-02-baseline/summary.md): gpt-4.1-mini가 시드를 고르고 Last.fm 유사곡으로 넓힌 뒤 iTunes로 해석해 한 번에 응답 (앱 코드 `e4cda32`)
- R5 (이 폴더): V5 프롬프트 · gpt-6-luna가 곡을 직접 고르고, 곡이 완성될 때마다 iTunes로 해석해 POST 스트림으로 곡마다 보낸다 (커밋 `ed3ebaf`, 작업 트리 clean)
- 입력: `inputs.json` 26개 + `repeat: true` 6개를 한 번 더 = 32회, 요청 사이 120초. 서버는 한 번 띄워 32회 내내 유지
- 기준선은 서비스를 프로세스 안에서 직접 불렀고, R5는 로컬 HTTP로 불렀다. 기준선은 9일 전 측정이라 같은 날 번갈아 잰 비교는 아니다

## 자동 지표

### 감정 — 총점은 같고, 틀리는 곳이 바뀌었다

| | 명확 | 애매 | 문맥 함정 | 틀린 입력 |
| --- | --- | --- | --- | --- |
| 기준선 | 12/12 | 12/12 | 0/2 | `context-sarcasm` → 놀람 · `context-resigned` → 안도 |
| R5 | 10/12 | 12/12 | 2/2 | `confident-clear` → 신남 · `joy-clear` → 신남 |

- 기준선은 웃음 표기(ㅋㅋ · ㅎㅎ) 뒤의 비꼼과 체념을 놀람 · 안도로 읽었다. 이렇게 틀리면 감정과 어긋난 방향의 곡이 나온다
- R5는 "6개월 준비한 발표를 오늘 완벽하게 해냈어"(정답 자신감)와 "드디어 최종 합격 문자 받았어!!"(정답 기쁨)를 신남으로 읽었다. 이웃한 긍정 감정끼리의 혼동이다. 11/10 응답 시간 측정(`2026-11-10-latency-ab`)에서도 두 입력을 똑같이 판정해 우연이 아니다
- 26개 중 2개라 어느 쪽 오류가 덜 해롭다고 일반화하지는 않는다. 고친다면 romance/excited 경계(C2)처럼 경계 한 줄을 넣고, 프롬프트가 바뀌므로 `PICK_PROMPT_VERSION`을 올린다

### 화면 곡과 iTunes 호출

- 기준선은 26회 모두 iTunes 차단(403 · 429)을 맞았다. 모드당 평균 1.9곡이 남았고, 심취 26개 중 11개는 0곡이었다
- R5는 차단이 0건이고 52개 모드가 모두 10곡을 채웠다
- 요청당 호출은 평균 36.4회(최대 61)에서 26.6회(최대 44)로 줄었다. 기준선은 시드와 유사곡을 한꺼번에 해석했고, R5는 곡이 완성될 때마다 하나씩 해석하다 화면이 차면 멈춘다

### 응답 시간

| | p50 | p90 |
| --- | --- | --- |
| 머리말 (감정 · 공감 문구) | 2.05s | — |
| 첫 곡 | 2.72s | 4.00s |
| 전체 | 7.39s | 9.27s |
| OpenAI 응답 | 6.36s | — |

- 첫 곡은 기준(2.5s)을 0.22s 넘었다. 같은 구조로 잰 11/10에는 3.18s였다. LLM 속도가 시간대마다 달라서 2.5~3.2s 사이를 오간다
- 기준선은 곡을 한꺼번에 받는 구조라 첫 곡이 곧 전체(8.7s)였다. 사용자가 첫 곡을 보는 시점은 약 6초 당겨졌다
- 줄일 후보는 응답 순서 실험(곡을 공감 문구보다 먼저 쓰게)이다. 선곡 품질이 바뀔 수 있어 얼린 빌드와 번갈아 재야 한다

### 같은 글 다시 + 이력

반복 6개 입력에서, 첫 화면 곡을 이력으로 보낸 두 번째 화면 10곡 중 첫 화면에서 본 곡 수다.

- 심취 평균 0.8곡(최대 `joy-clear` 3곡), 완화 0곡
- 판단선(심취 평균 3곡 이상이면 심취도 15곡으로 늘리는 안을 다시 잰다)에 못 미쳐 **심취는 12곡 그대로 둔다**

## 블라인드 무드 적합도

방식: 묶음 = 입력 × 모드. 기준선 화면 곡 k개와 R5 화면 곡 중 고정 시드로 뽑은 k개를 섞어, 출처 없이 곡마다 1~5점을 매겼다. 40묶음 · 201줄이고, 기준선이 0곡인 12묶음은 뺐다. 사용자가 전부 매겼고(판정), Claude는 새 에이전트에 같은 시트만 주고 따로 매겼다(일치도 확인). 결과 전체는 [`blind/summary.md`](blind/summary.md).

### 평가자 일치도

- 둘 다 매긴 189곡에서 점수 차가 1 이하인 곡이 80%, 같은 점수가 34%다. Claude가 평균 0.71점 낮게 줬다
- 점수 분포가 다르다. 사용자는 4~5점이 199곡 중 132곡이고, Claude는 3점이 189곡 중 98곡이다. 사용자 쪽이 천장에 몰려 무승부가 13묶음 나왔다
- 묶음별 승패 방향(38묶음)은 같은 방향 18, 정반대 6, 한쪽만 무승부 14다

### R5가 진 묶음

| 입력 · 모드 | k | 차이 | 내용 |
| --- | --- | --- | --- |
| `anger-clear` 완화 | 1 | −2.00 | R5 「피해망상, Pt. 1」(에픽하이) 1점 vs 기준선 「Don't Know Why」(Norah Jones) 3점 |
| `neutral-clear` 완화 | 3 | −1.00 | R5 「꽃」(정밀아) 2점 · 「숲」 · 「Heartbeats」 3점 |
| `romance-clear` 완화 | 2 | −1.00 | R5 「Flavor Of Life」(우타다 히카루) 2점 · 「Like a Star」 3점 |
| `neutral-ambig` 심취 | 5 | −0.20 | 5곡씩, 평균 3.60 vs 3.80 |

`anger-clear` 완화는 한 묶음이지만 구조적인 원인이 보인다. 실제 화면의 완화 10곡은 이렇다.

1. 한국 6곡: 「피해망상, Pt. 1」 · 「검은 행복」 · 「죽일 놈」 · 「나는 이영지」 → 「한 페이지가 될 수 있게」 · 「ONLY」
2. 팝 3곡: 「HUMBLE.」 → 「Breathe Me」 · 「Easy On Me」
3. 일본 1곡: 「Lemon」

- 프롬프트는 완화를 "지금 감정에 맞닿은 곡에서 시작해 차분한 곡으로 옮겨 가는 흐름"으로 고르게 한다(C3, iso principle)
- 화면 목록은 지역별로 묶여(한국 → 팝 → 일본) 나오고, 흐름이 지역마다 처음부터 다시 시작한다. 한국 첫 곡도 팝 첫 곡도 공격적인 곡이고, 분노를 달래는 목록이 그런 곡 네 곡으로 열린다
- 곡 수를 지역별로 지시하니(한국 8 · 팝 5 · 일본 2) 지역 목록마다 저마다 지금 감정에서 출발하는 것으로 보인다(추정 — LLM 원응답 순서는 기록하지 않았다)
- 곡 단위 블라인드는 곡을 하나씩 따로 보므로, 흐름 앞쪽의 "감정에 맞닿은 곡"은 설계대로여도 완화 점수가 낮게 나온다
- 입력 하나에서 본 것이라, 다른 감정의 완화 첫 곡도 같은지 확인하는 것이 다음 일이다

### 한계

- **반복곡으로 출처를 짐작할 수 있었다.** 기준선 101줄 중 4곡이 47줄이다: ZARD 「心を開いて」 18 · Norah Jones 「Don't Know Why」 14 · 「Come Away With Me」 9 · Alicia Keys 「No One」 6. R5 쪽에서 가장 많이 나온 곡은 3줄이다. 사용자도 평가 중에 "노라 존스 · ZARD · 앨리샤 키스 · 윤하가 너무 많이 나온다"고 적었다(앞의 셋은 모두 기준선 곡, 윤하는 양쪽에 있다). Claude도 같은 시트를 봤으니 같은 단서를 봤을 수 있다
- **평가자**: 사용자는 운영자라 지금 서비스의 곡을 알아볼 수 있다. Claude는 곡을 듣지 않고 아는 지식으로만 매겼다(모름 12곡)
- **표본**: 묶음마다 R5는 화면 10곡 중 k곡(기준선 곡 수, 1~5)만 봤다. 기준선이 0곡인 12묶음은 블라인드에서 빠지고 화면 곡 수율(19%)로만 반영된다
- **모델과 시점**: 기준선은 gpt-4.1-mini로 9일 전에 쟀다. 모델 · 선곡 구조 · 전송 방식이 한꺼번에 바뀐 비교라, 개선을 한 가지 원인에 돌리지 않는다

## 결론과 다음

재설계(AI 직접 선곡 · 곡 단위 해석 · 스트리밍)는 감정 일치를 유지했고, 화면 곡 수 · iTunes 차단 · 첫 곡 시점을 크게 개선했다. 무드 적합도도 떨어지지 않았다(두 평가자 모두 R5가 높다). 첫 곡 2.5s 기준만 아직 못 맞췄다.

- 심취 15곡: 하지 않는다 (같은 글 다시 0.8곡 < 3)
- 선곡 변형 V0~V4: 걷고 V5로 고정했다 (11/11, 측정 기록 이름 `PICK_PROMPT_VERSION`)
- 다음 후보
  - 완화 첫 곡 점검: 흐름이 지역마다 다시 시작하는지 다른 감정에서도 확인
  - 기쁨 · 자신감 / 신남 경계 한 줄
  - 첫 곡 2.5s: 응답 순서 실험(곡을 공감 문구보다 먼저)
